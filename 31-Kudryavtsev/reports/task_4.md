# Задача 4. Все индексы элемента

## Идея решения

Исходные числа хранятся в массиве `int[]`. При переборе индексы совпадений записываются
в отдельный массив слева направо, поэтому они сразу идут по возрастанию.
В результат копируются только найденные индексы. Если совпадений нет, выводится пустая строка.
Ввод: размер массива, элементы, затем искомое число.

## Асимптотика

Поиск выполняет `n` сравнений, копирование и вывод обрабатывают по `k` найденных индексов.
Так как `k` не больше `n`, общее время — `O(n)`.
Исходный и временный массивы занимают по `O(n)`, результат — `O(k)`. Общая память — `O(n)`.

## Ручные тесты

| Ввод: размер, элементы, искомое число | Вывод | Что проверяется |
|---|---|---|
| `5 7 2 7 3 7 7` | `0 2 4` | Порядок нескольких индексов |
| `2 1 2 7` | пустая строка | Отсутствие совпадений |
| `3 4 4 4 4` | `0 1 2` | Все элементы совпадают |
| `4 -1 2 -1 -1 -1` | `0 2 3` | Отрицательное искомое число |
| `2 0 0 0` | `0 1` | Нулевые элементы и минимальный размер |
