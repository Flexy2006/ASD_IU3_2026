# Задача 6. Элементы больше среднего

## Идея решения

В массиве `int[]` сохраняются числа для повторного прохода.
Сначала находится сумма типа `long` и делится на размер. По условию среднее целое.
Затем считаются элементы строго больше среднего; равные ему не подходят.
Ввод: размер массива и элементы. Вывод: количество.

## Асимптотика

Чтение и два прохода обрабатывают по `n` элементов: общее время — `O(n)`.
Массив занимает `O(n)` памяти, сумма, среднее и счётчик — `O(1)` дополнительно.

## Ручные тесты

| Ввод: размер и элементы | Вывод | Что проверяется |
|---|---|---|
| `3 2 5 8` | `1` | Элемент, равный среднему, не считается |
| `3 -9 -6 -3` | `1` | Отрицательное среднее |
| `4 4 4 4 4` | `0` | Все элементы равны |
| `4 -6 -3 0 9` | `1` | Среднее равно нулю |
| `2 2147483647 2147483645` | `1` | Сумма не помещается в int |
