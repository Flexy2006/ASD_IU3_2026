# Задача 13. Сортировка выбором

## Идея решения

Используется массив `int[]`, чтобы менять элементы местами без дополнительного массива.
На каждой позиции ищется минимум оставшейся части и переносится на эту позицию обменом.
После проходов весь массив упорядочен по неубыванию. Встроенная сортировка не используется.
Ввод: размер массива и его элементы.

## Асимптотика

Количество сравнений равно `(n - 1) + (n - 2) + ... + 1 = n(n - 1) / 2`.
Время сортировки — `O(n²)`, в том числе для уже отсортированного массива.
Дополнительная память сортировки — `O(1)`, общая память с входным массивом — `O(n)`.

## Ручные тесты

| Ввод: размер и элементы | Вывод | Что проверяется |
|---|---|---|
| `5 4 -2 0 7 -5` | `-5 -2 0 4 7` | Смешанные значения |
| `4 -3 0 2 9` | `-3 0 2 9` | Массив уже отсортирован |
| `4 9 5 2 -1` | `-1 2 5 9` | Обратный порядок |
| `5 3 1 3 1 2` | `1 1 2 3 3` | Повторяющиеся элементы |
| `2 8 -4` | `-4 8` | Минимальный допустимый размер |
