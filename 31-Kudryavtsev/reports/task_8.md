# Задача 8. Фильтрация по знаку

## Идея решения

Из исходного `int[]` создаются два массива: для положительных и отрицательных чисел.
Первый проход определяет их размеры, второй заполняет в исходном порядке. Нули пропускаются.
Ввод: размер и элементы. Вывод: положительные числа на первой строке, отрицательные на второй.
Если группа пустая, выводится пустая строка.

## Асимптотика

Два прохода требуют `2n` проверок, чтение и вывод также линейные. Общее время — `O(n)`.
Исходный массив и два результата вместе занимают `O(n)` памяти; дополнительные массивы — `O(n)`.

## Ручные тесты

| Ввод: размер и элементы | Первая строка | Вторая строка | Что проверяется |
|---|---|---|---|
| `6 3 -2 0 1 -5 4` | `3 1 4` | `-2 -5` | Сохранение порядка и пропуск нуля |
| `3 2 2 1` | `2 2 1` | пустая | Только положительные числа, повторы остаются |
| `3 -1 -3 -2` | пустая | `-1 -3 -2` | Только отрицательные числа |
| `2 0 0` | пустая | пустая | Обе группы пустые |
| `2 -2147483648 2147483647` | `2147483647` | `-2147483648` | Минимальный размер и границы int |
