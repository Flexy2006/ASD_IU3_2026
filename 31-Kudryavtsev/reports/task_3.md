# Задача 3. Подсчёт вхождений

## Идея решения

Числа сохраняются в массиве `int[]`. При переборе каждый элемент сравнивается с искомым числом.
За каждое совпадение счётчик увеличивается на единицу. Начальное значение счётчика — ноль.
Ввод: размер массива, элементы, затем искомое число.

## Асимптотика

Чтение обрабатывает `n` чисел, поиск выполняет `n` сравнений. Общее время — `O(n)`.
Для массива нужно `O(n)` памяти, для счётчика и остальных переменных — `O(1)`.

## Ручные тесты

| Ввод: размер, элементы, искомое число | Вывод | Что проверяется |
|---|---|---|
| `5 4 -2 4 0 4 4` | `3` | Несколько совпадений в разных местах |
| `2 1 2 7` | `0` | Число отсутствует |
| `3 6 6 6 6` | `3` | Все элементы совпадают |
| `4 0 2 0 -1 0` | `2` | Подсчёт нулей |
| `2 -3 -3 -3` | `2` | Отрицательные числа и минимальный размер |
