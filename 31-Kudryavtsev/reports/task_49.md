# Задача 49. Сумма строк матрицы

## Идея решения

Матрица хранится в двумерном массиве `int[][]`. Для каждой строки складываются все её элементы.
Результаты записываются в массив `long[]`, чтобы сумма не переполняла тип `int`.
Ввод: число строк `n`, число столбцов `m`, затем элементы по строкам.

## Асимптотика

Ввод и подсчёт обрабатывают по `n × m` элементов. Время программы — `O(nm)`.
Матрица занимает `O(nm)` памяти, массив сумм — `O(n)`. Общая память — `O(nm)`.

## Ручные тесты

| Ввод: n, m и элементы по строкам | Вывод | Что проверяется |
|---|---|---|
| `2 3 1 2 3 4 5 6` | `6 15` | Прямоугольная матрица |
| `2 2 0 0 0 0` | `0 0` | Нулевые элементы |
| `2 2 -1 -2 -3 -4` | `-3 -7` | Отрицательные суммы |
| `1 3 2 -1 4` | `5` | Одна строка |
| `2 2 2147483647 2147483647 -2147483648 -2147483648` | `4294967294 -4294967296` | Суммы за пределами int |
