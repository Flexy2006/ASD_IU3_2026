й# Задача 54. Сумма элементов на главной диагонали

## Идея решения

Квадратная матрица сохраняется в массиве `int[][]`. На главной диагонали индексы строки и столбца
совпадают, поэтому складываются элементы `matrix[i][i]`. Для суммы используется тип `long`.
Ввод: размер `n`, затем элементы матрицы по строкам.

## Асимптотика

Подсчёт суммы делает `n` сложений: время `O(n)`, дополнительная память `O(1)`.
Чтение всех `n²` элементов занимает `O(n²)` времени.
Вся программа требует `O(n²)` времени и `O(n²)` памяти для хранения матрицы.

## Ручные тесты

| Ввод: n и элементы по строкам | Вывод | Что проверяется |
|---|---|---|
| `3 1 2 3 4 5 6 7 8 9` | `15` | Главная диагональ матрицы 3 × 3 |
| `2 4 99 -8 6` | `10` | Числа вне главной диагонали не учитываются |
| `2 -3 0 0 -2` | `-5` | Отрицательные элементы диагонали |
| `2 0 5 -4 0` | `0` | Нулевая диагональ |
| `2 2147483647 0 0 2147483647` | `4294967294` | Сумма за пределами int |
