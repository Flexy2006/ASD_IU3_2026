# Задача 5. Сумма элементов на чётных позициях

## Идея решения

Числа хранятся в массиве `int[]`. Перебор начинается с индекса 0 с шагом 2.
Выбирается чётный индекс, а значение элемента может быть любым.
Сумма хранится в `long`, чтобы избежать переполнения `int`.
Ввод: размер массива и элементы. Вывод: сумма.

## Асимптотика

Чтение требует `n` действий, суммирование — около `n / 2`. Общее время — `O(n)`.
Массив занимает `O(n)` памяти, дополнительные переменные — `O(1)`.

## Ручные тесты

| Ввод: размер и элементы | Вывод | Что проверяется |
|---|---|---|
| `5 1 2 3 4 5` | `9` | Учитывается последний элемент при нечётной длине |
| `4 3 100 5 200` | `8` | Выбор по индексу, а не по чётности числа |
| `2 -7 10` | `-7` | Минимальный размер и отрицательная сумма |
| `4 0 8 0 9` | `0` | Нули на выбранных позициях |
| `3 2147483647 0 2147483647` | `4294967294` | Сумма больше максимального int |
