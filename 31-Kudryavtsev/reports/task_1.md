# Задача 1. Максимум и минимум

## Идея решения

Числа хранятся в массиве `int[]`, так как для поиска достаточно последовательно перебрать его элементы.
Минимум и максимум сначала равны первому элементу. Затем каждый следующий элемент сравнивается
с ними, и при необходимости значения обновляются. Начальные значения берутся из массива,
чтобы правильно обрабатывать положительные и отрицательные числа.

## Асимптотика

Чтение требует `n` операций, поиск — `n - 1` итераций по два сравнения: всего `2(n - 1)` сравнений.
Общее время работы — `O(n)`.
Массив занимает `O(n)` памяти, а дополнительные переменные и результат поиска — `O(1)`.
Общая память программы — `O(n)`.

## Ручные тесты

| Ввод: размер и элементы | Вывод | Что проверяется |
|---|---|---|
| `6 8 -3 12 0 -9 5` | `-9 12` | Смешанные числа, минимум и максимум внутри массива |
| `4 7 3 11 6` | `3 11` | Только положительные числа |
| `4 -7 -3 -11 -6` | `-11 -3` | Только отрицательные числа |
| `3 4 4 4` | `4 4` | Все элементы равны |
| `2 12 -8` | `-8 12` | Минимальный допустимый размер массива |
