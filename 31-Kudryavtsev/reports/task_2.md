# Задача 2. Индекс первого вхождения

## Идея решения

Используется массив `int[]`. Элементы перебираются слева направо.
При первом совпадении возвращается его индекс. Если совпадений нет, возвращается -1.
Ввод: размер массива, элементы, затем искомое число. Индексы начинаются с нуля.

## Асимптотика

Поиск выполняет не более `n` сравнений: в худшем случае время `O(n)`, при совпадении в начале — `O(1)`.
С учётом чтения всего массива общее время — `O(n)`.
Массив занимает `O(n)` памяти, дополнительные переменные поиска — `O(1)`.

## Ручные тесты

| Ввод: размер, элементы, искомое число | Вывод | Что проверяется |
|---|---|---|
| `5 7 3 7 0 7 7` | `0` | Возвращается первое из нескольких совпадений |
| `4 1 4 8 2 8` | `2` | Число в середине массива |
| `2 1 2 7` | `-1` | Число отсутствует |
| `4 6 -2 0 -2 -2` | `1` | Отрицательное искомое число |
| `2 0 9 9` | `1` | Последний элемент и минимальный размер |
