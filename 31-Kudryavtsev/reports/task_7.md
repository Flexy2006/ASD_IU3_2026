# Задача 7. Второй максимум

## Идея решения

Используется массив `int[]` и две переменные: максимум и второй максимум.
Начальные значения берутся из первых двух элементов, поэтому подходят и отрицательные числа.
При новом максимуме прежний становится вторым. Иначе проверяется только второй максимум.
Все числа различны по условию. Ввод: размер и элементы. Вывод: второй максимум.

## Асимптотика

Чтение требует `n` действий, поиск — не более двух сравнений для каждого из оставшихся `n - 2` чисел.
Общее время — `O(n)`. Массив занимает `O(n)` памяти, поиск требует `O(1)` дополнительной памяти.

## Ручные тесты

| Ввод: размер и элементы | Вывод | Что проверяется |
|---|---|---|
| `5 3 9 1 7 5` | `7` | Второй максимум обновляется без замены первого |
| `4 1 3 5 7` | `5` | Каждый следующий элемент больше предыдущего |
| `4 9 7 3 1` | `7` | Оба наибольших числа стоят в начале |
| `3 -9 -2 -5` | `-5` | Все числа отрицательные |
| `2 -2147483648 2147483647` | `-2147483648` | Минимальный размер и границы int |
